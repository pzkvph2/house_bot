Асинхронный Telegram-бот на **aiogram 3.x** и **SQLAlchemy 2.0 (asyncio + SQLite)**, оптимизированный под арбитраж условно-бесплатного трафика (УБТ из TikTok, Reels, Shorts) в нише EdTech для Казахстана.

---

Особенности архитектуры

1. **Мультиязычность RU / KZ (i18n):**
   - Выбор языка при старте (`/start`) с сохранением в БД.
   - Все тексты вынесены в `data/locales.json` с поддержкой казахского и русского языков.
   - Поддерживает горячее редактирование без перезапуска процесса.

2. **Динамические офферы без хардкода:**
   - Офферы хранятся в `data/offers.json`.
   - Поддержка статуса (`is_active: true/false`), приоритета показа, локализованных названий и описаний.
   - Автоматическая генерация партнерских ссылок с макросом `{user_id}` в `subID` для отслеживания конверсий в CPA-сетях (Admitad, Lerna, AdvCake и др.).

3. **База данных для дожима (Retargeting):**
   - Таблица `users` фиксирует: `user_id`, `@username`, язык, дату первого входа, а также **`last_clicked_offer_id`** и дату последней активности.
   - Готовая база для сегментированных рассылок (например, отправить пуш со скидкой тем, кто кликал на «IT-профессии», но не завершил регистрацию).

4. **Прелендинг-прокладка с триггерами РК:**
   - Меню направлений открывает карточку с триггерами: **Kaspi Рассрочка 0-0-12 / 0-0-24**, скидки до 60% и прямая кнопка перехода.

## 📁 Структура проекта

```text
├── config.py             # Настройки Pydantic Settings и пути к файлам
├── database/
│   ├── db.py             # Асинхронный движок SQLAlchemy и управление сессиями
│   └── models.py         # Описание модели User
├── services/
│   ├── i18n.py           # Сервис локализации (RU/KZ) на базе locales.json
│   ├── offers.py         # Сервис динамических офферов и сборки партнерских URL
│   └── user_service.py   # Слой взаимодействия с БД пользователей
├── keyboards/
│   └── inline.py         # Фабрики инлайн-клавиатур (язык, меню, офферы)
├── handlers/
│   └── user.py           # Хэндлеры /start, смены языка, кликов по офферам
├── data/
│   ├── locales.json      # Тексты интерфейса (RU/KZ)
│   └── offers.json       # Конфиг партнерских программ
├── main.py               # Точка входа в бота
├── requirements.txt      # Зависимости
├── .env.example          # Шаблон переменных окружения
└── README.md             # Документация
```

Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate   # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка конфигурации

Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните свой токен бота, полученный от [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ_sample
DATABASE_URL=sqlite+aiosqlite:///bot.db
CHANNEL_URL=https://t.me/your_kz_channel
```

### 3. Запуск бота

```bash
python main.py
```
Бот автоматически создаст базу данных `bot.db` и применит схему таблиц при первом старте.
